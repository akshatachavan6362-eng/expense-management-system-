# Expense Management System

A web-based Expense Management System developed using PHP, MySQL, HTML, CSS and JavaScript.

## 📌 About the Project

The Expense Management System helps users manage and track their personal expenses through a simple web interface.

## 🚀 Features

- User Registration and Login
- User Authentication
- Add and Manage Expenses
- View Expense Details
- Expense Reports
- Category Management
- User-friendly Interface
- Logout Functionality

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## 💻 Project Type

Web Application

## 🎯 Purpose

This project was developed as a BCA academic project to gain practical experience in web development, database management and PHP programming.
